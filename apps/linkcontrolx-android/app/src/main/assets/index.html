Permissions & limits

Camera — used only to read a QR code. The browser asks your permission, and it only works over HTTPS (or localhost). Nothing is uploaded.

Notifications — optional, for in-app alerts. You can deny them with no loss of core features.

No remote control — a website cannot see or control another phone's screen. Android sandboxes every app. Real device control needs a native app with the owner's explicit, on-screen consent.

No real scanning — this app only inspects this browser/device locally. It never probes a network or another machine.
